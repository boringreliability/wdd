## Specification

### WORKING MEMORY (generated)
For each in-flight Ward (status ∈ planned, red, approved, gold, blocked — anything except `complete`), print:

```
═══ WORKING MEMORY ═══
In flight (this checkout):
  context-001  planned   Derived working memory
  orchestration-020 planned   Planning Metadata Frontmatter

Next:
  (first in-flight Ward in list order — same order as listWardFiles)

Blocked:
  (in-flight Wards with status blocked, or planned Wards whose deps are incomplete)

Filter: all epics
```

When `--epic context` is passed:
- Only Wards with `frontmatter.epic === "context"` (legacy files: epic field or scoped path)
- `CURRENT WARD` also prefers the first in-flight Ward **in that epic**, not the first incomplete file in the whole repo
- Header line: `Filter: epic context`

Complete Wards never appear. `PROGRESS.md` remains the historical table.

### CONTEXT.md in session
`═══ CONTEXT ═══` still exists but must **not** dump the full diary. Render only:
- `#` title if present
- `## Active Constraints` section (code-fence-aware `extractSection` from Ward 15b)
- If that heading is missing: one line `⚠ CONTEXT.md has no Active Constraints section — add invariants there, not a log.`

Do not render Architecture Decisions, Key Metrics, Release History, Current State, or What Comes Next from CONTEXT.md. Those belong in `memory/decisions`, `PROGRESS.md`, and WORKING MEMORY respectively.

### Logbook detection (`wdd validate`)
Errors (exit non-zero), each naming the heading or pattern:

| Pattern | Why |
|---------|-----|
| Heading `## Architecture Decisions Made` | Decisions live in `memory/decisions/` |
| Heading `## Key Metrics` | Duplicates `PROGRESS.md` |
| Heading `## Release History` | That is a changelog |
| Heading `## Current State` whose body matches `Ward \d+ complete` or `Ward \`[a-z0-9-]+\` complete` | Completion narrative |
| A markdown table under Architecture Decisions / Key Metrics | Same |

Allowed (and required):
- `## Active Constraints` (may be empty / placeholder)
- Optional `## Known Blockers` with pointers to BACKLOG ids or Ward ids — no diary prose required
- Line/byte limits **remain** (200 / 8KB) as a backstop

Missing `## Active Constraints` is an error.

Do **not** auto-edit CONTEXT.md. Validate only.
